# FY2025 NCAA financial reports: public records requests

Every NCAA Division I school files an annual NCAA Membership Financial Reporting System (MFRS) report. Ohio State, Illinois and Wisconsin post theirs publicly. For the 12 schools below, no public copy was found (searched 2026-10-22: athletics websites, news coverage, regents/system sites). All 12 are public universities, so the report can be requested under state public records law.

## Schools to request from

| School | State law | How to find the office |
|---|---|---|
| Rutgers | NJ Open Public Records Act (OPRA) | Search "Rutgers OPRA request" |
| University of Iowa | Iowa Open Records Law (Ch. 22) | Search "University of Iowa public records request" |
| Clemson | SC Freedom of Information Act | Search "Clemson FOIA request" |
| University of Utah | Utah GRAMA | Search "University of Utah GRAMA request" |
| University of Maryland | Maryland Public Information Act | Search "University of Maryland PIA request" |
| UCLA | California Public Records Act | Search "UCLA public records request" |
| University of Minnesota | Minnesota Data Practices Act | Search "University of Minnesota data request" |
| Purdue | Indiana Access to Public Records Act | Search "Purdue public records request" |
| Michigan State | Michigan FOIA | Search "Michigan State FOIA office" |
| University of Arizona | Arizona Public Records Law | Search "University of Arizona public records request" |
| Arizona State | Arizona Public Records Law | Search "ASU public records request" |
| University of Texas at Austin | Texas Public Information Act | Search "UT Austin open records request" |

Most offices have a web form. Requests for an existing document like this are usually fulfilled in a few days to a few weeks, often free.

## Request text (copy, paste, fill in the school name)

> Under [state public records law], I request an electronic copy (PDF) of the NCAA Membership Financial Reporting System (MFRS) report, including the agreed-upon procedures report, filed by [University] Athletics for fiscal year 2025 (July 1, 2024 – June 30, 2025, or the institution's FY2025 reporting period).
>
> This is an existing document submitted to the NCAA in or around January 2026. If any portion is withheld, please release the remainder and cite the exemption applied.
>
> Please send the record by email. Thank you.
